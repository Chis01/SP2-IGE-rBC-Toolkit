# GitHub repository metadata

**Suggested name:** `sp2-ige-rbc-toolkit`

**Short description (GitHub About field):**

Igor Pro workflows for time-resolved SP2 analysis of refractory black carbon in snow and ice, with AquaDAG recovery correction and particle diagnostics.

**Extended academic description:**

SP2 IGE rBC Toolkit is a research-oriented Igor Pro extension for reproducible processing of Single Particle Soot Photometer (SP2) measurements of refractory black carbon (rBC) in melted snow and ice. Built for Igor Pro 6.37 and PSI SP2 Toolkit 4.111, it combines explicitly defined time windows, native SP2 incandescence post-processing, liquid-sample concentration conversion, AquaDAG recovery calibration, blank and standard quality controls, and optional analysis of single-particle rBC mass and mass-equivalent diameter. Number- and mass-weighted particle-size diagnostics are provided as research outputs requiring independent runtime and export validation. Optical diameter, leading-edge-only scattering reconstruction, and coating thickness are not implemented as validated outputs. The software is instrument-configuration dependent and should not be used for quantitative interpretation without laboratory-specific calibration and quality assurance.
